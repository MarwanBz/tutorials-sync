# Tutorials Sync

My personal learning platform for mastering frontend development.

I learn by chatting with AI, save the best insights as tutorials, then practice with quizzes to reinforce what I've learned.

> **Disclaimer:** All tutorials and posts on this site are AI-generated content captured from my learning sessions with AI agents on my local codebases. Code snippets and examples are drawn directly from my own projects. This content is created for my personal reference, practice, and self-quizzing as I deepen my understanding of frontend development.

## Features

- **Tutorials** - Deep dives into React, databases, HTTP, and more
- **Quizzes** - Test your understanding with active recall
- **Progress Tracking** - See improvement over time
- **Write Dashboard** - Create and edit content easily

## How I Use It

1. Learn something valuable in an AI chat
2. Save it as a tutorial via the Write dashboard
3. Create quizzes to test myself later
4. Track progress and review over time

Built with React, Convex, and Vite.
